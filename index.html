🚀 Basics — Getting Started with SPSS

Interface orientation, opening files, variable setup, and key concepts before running any analysis.

🖥️Interface Overview

Data Editor — Data View

The spreadsheet view where each row = one case (participant) and each column = one variable. All raw data is entered and viewed here.

Data Editor›Data View tab (bottom)
📘 Key Concepts
Each row is an observation (patient, subject, record). Each column is a variable. Missing values appear as a dot (.) by default.

Data Editor — Variable View

Define variable properties: name, type, label, value labels, missing values, and measurement level. Always configure this before analysis.

Data Editor›Variable View tab (bottom)
📘 Measurement Levels
Scale (Continuous): numeric with meaningful intervals (age, BP, weight)
Ordinal: ranked categories (Likert, disease severity)
Nominal: unordered categories (gender, blood group, diagnosis)
⚠️ Critical Step
Wrong measurement level = wrong analysis options appear in menus. Always set this first.

Open Data File (.sav / Excel / CSV)

File›Open›Data…
  • Browse to file location
  • Change Files of type to match format (.sav, .xlsx, .csv)
  • Click Open
  • For Excel: check Read variable names from first row → OK

Import CSV / Text File

File›Import Data›CSV Data…
  • Select your .csv file → Next
  • Confirm delimiter (comma, tab, space)
  • Check Variable names at top of file → Finish

Save / Save As

Save current file
File›Save Ctrl+S
Save as new name/format
File›Save As…

Save as .sav (SPSS format) to preserve variable labels and value codes. Export to Excel/CSV loses metadata.

Output Viewer

All analysis results appear in the Output Viewer window as tables and charts. Each run adds new output to the bottom.

Window›IBM SPSS Statistics Viewer
📘 Output Tips
Use the left-side outline panel to jump to any result. Right-click any table → Export to copy to Word/Excel. Double-click a chart to open Chart Editor.

📐Normality Testing (First Step Before Any Test)

Shapiro-Wilk & Kolmogorov-Smirnov

Test whether your continuous variable is normally distributed. This determines whether to use parametric or non-parametric tests.

Analyze›Descriptive Statistics›Explore…
  • Move continuous variable(s) to Dependent List
  • Optionally move grouping variable to Factor List
  • Click Plots… → check ☑ Normality plots with tests → Continue
  • Click OK
📘 Theory
Shapiro-Wilk (SW) is generally preferred regardless of sample size — it is more powerful and sensitive than KS for detecting departures from normality.
Kolmogorov-Smirnov (KS): an older alternative, less powerful; only use if specifically required by a reviewer or journal.

H₀: Data is normally distributed
p > 0.05 → fail to reject H₀ → use parametric tests
p ≤ 0.05 → data is NOT normal → use non-parametric alternatives
📝 APA Reporting
Normality was assessed via the Shapiro-Wilk test. Results indicated the data were normally distributed, W(n) = .xxx, p = .xxx.
Essential First StepBefore Every Test

Levene's Test of Homogeneity of Variance

Tests whether groups have equal variances — required before independent t-tests and ANOVA.

Analyze›Compare Means›One-Way ANOVA…›Options: Homogeneity of variance test
📘 Theory
p > 0.05: Equal variances assumed (use standard test)
p ≤ 0.05: Variances are unequal → use Welch correction (for t-test: "Equal variances not assumed" row; for ANOVA: Welch F statistic)
ℹ️ Workflow Before Every Analysis
1. Check Variable View — correct measurement levels
2. Run Explore — check normality (SW/KS tests)
3. Check Levene's — equal variances if comparing groups
4. Then choose the appropriate test

🗄️ Data Management

Transform, clean, filter, sort, and restructure your dataset using SPSS menus.

🔧Variable Transformations

Compute New Variable

Create a new variable from a mathematical expression (e.g., BMI = weight/height²).

Transform›Compute Variable…
  • Enter a name in Target Variable
  • Build expression in Numeric Expression box (use keyboard or function list)
  • Optionally click If… to compute only for cases meeting a condition
  • Click OK

Example: weight / (height * height) for BMI. Use LN(), SQRT(), ABS() functions from the list.

Recode Into Different Variable

Create a new categorical variable from an existing one (e.g., age → age group). Always use "Different Variable" to preserve original data.

Transform›Recode into Different Variables…
  • Move source variable to Input Variable → Output Variable
  • Enter Name for new variable → click Change
  • Click Old and New Values…
  • Enter each old value (or range) → new value → Add
  • Continue → OK

After recoding: go to Variable View → set Measure to Nominal/Ordinal and add Value Labels for the new variable.

Visual Binning (Categorize Continuous)

Convert a continuous variable (age, score) into ordered categories using a visual histogram interface.

Transform›Visual Binning…
  • Move variable into Variables to Bin → Continue
  • Enter a Binned Variable Name
  • Click Make Cutpoints… → set equal-width or percentile bins, or drag boundaries manually
  • Assign category Labels (e.g., 0–18, 19–35, 36+) → OK

Recode Into Same Variable

Replace values within an existing variable. Use only if you no longer need the original values.

Transform›Recode into Same Variables…
  • Move target variable(s) to Variables
  • Click Old and New Values…
  • Enter old → new value pairs → Add → Continue → OK
⚠️ Warning
This permanently overwrites the original values. Prefer Recode into Different Variable.

Standardize (Z-Score) a Variable

Convert a variable to z-scores (mean=0, SD=1) for comparisons across different scales.

Analyze›Descriptive Statistics›Descriptives…
  • Move variable(s) to Variable(s) list
  • Check ☑ Save standardized values as variables
  • Click OK

New variable Zvarname is created in the dataset. Formula: Z = (X − Mean) / SD.

📘 Z-Score Formula
Z = (X − μ) / σ
Useful for detecting outliers: |Z| > 3 = potential outlier.

Rank Cases

Assign ranks to cases for non-parametric analyses or to create rank-transformed variables.

Transform›Rank Cases…
  • Move variable(s) to Variables
  • Optionally move grouping variable to By to rank within groups
  • Click Rank Types… → select Ranks, Fractional rank, Savage scores, etc.
  • Click Ties… → select how ties are handled → Continue → OK

🔍Data Filtering & Restructuring

Select Cases (Filter)

Temporarily restrict analysis to a subset of cases meeting a condition (e.g., only adults, only treatment group).

Data›Select Cases…
  • Choose If condition is satisfied → click If…
  • Enter logical condition (e.g., age >= 18, group = 1)
  • Choose Filter unselected cases (keeps rows, marks them) or Delete unselected cases
  • Continue → OK

Filtered rows show a slash (/) through row number. Reset: Data › Select Cases › All Cases.

Split File (Group Analyses)

Run all subsequent analyses separately for each group defined by a grouping variable.

Data›Split File…
  • Select Compare groups or Organize output by groups
  • Move grouping variable to Groups Based on
  • Click OK

⚠️ Always reset when done: Data › Split File › Analyze all cases.

Sort Cases

Data›Sort Cases…
  • Move sort key variable(s) to Sort by
  • Choose Ascending or Descending for each key
  • Click OK

Merge Files — Add Cases (Rows)

Append rows from a second dataset (same variables, more participants).

Data›Merge Files›Add Cases…
  • Select the second dataset (open or from file)
  • Match variable pairs if names differ
  • Exclude unmatched variables if needed → OK

Merge Files — Add Variables (Columns)

Join a second dataset by a key variable (like a database JOIN — same participants, more variables).

Data›Merge Files›Add Variables…
  • Select second dataset → choose Match cases on key variables
  • Move the ID/key variable to Key Variables
  • Both datasets must be sorted by the key variable first → OK

Restructure Data (Wide ↔ Long)

Convert between wide format (one row per subject, multiple time-point columns) and long format (one row per measurement).

Data›Restructure…
  • Choose Restructure selected variables into cases (wide → long) or vice versa
  • Follow the wizard: identify the subject ID, variable groups, and index variable
  • Finish → creates new dataset

Long format required for Mixed Models and Repeated Measures in many contexts.

❓Missing Values & Data Quality

Missing Value Analysis (MVA)

Identify patterns of missingness and decide on appropriate imputation strategy.

Analyze›Missing Value Analysis…
  • Move quantitative variables to Quantitative Variables
  • Click Patterns… → display missing pattern → Continue
  • Click Descriptives… → check Univariate statistics → Continue
  • Click OK
📘 Missing Data Mechanisms
MCAR (Missing Completely At Random): unrelated to any variable — listwise deletion acceptable
MAR (Missing At Random): related to observed data — use MI or EM
MNAR (Missing Not At Random): related to the missing value itself — most problematic
Medical ResearchEssential

Multiple Imputation (MI)

Replace missing values with multiple plausible estimates, creating several complete datasets for pooled analysis.

Analyze›Multiple Imputation›Impute Missing Data Values…
  • Select variables for imputation on the Variables tab
  • Set Number of imputations (recommended: 5–20)
  • Click Constraints… → set variable-specific bounds → Continue
  • Click Output… → specify save options → OK

Creates new pooled dataset marked as "imputed." Run analyses on this dataset and SPSS auto-pools results.

📘 When to Use MI
Use when missing data is MAR and missing rate > 5%. More imputations = more stable estimates. Requires SPSS Missing Values add-on module.

Validate Data (Range & Consistency Checks)

Data›Validate›Validate Data…
  • Click Rules tab → define single-variable rules (e.g., age 18–100)
  • Add cross-variable rules (e.g., pregnancy = yes only if sex = female)
  • Click Violations tab → choose handling
  • Click Output tab → select reports → OK
Clinical Research

Identify Duplicate Cases

Data›Identify Duplicate Cases…
  • Move matching variables (e.g., PatientID) to Define matching cases by
  • Choose sort order within groups
  • Select first or last case as primary
  • Click Indicator to create a duplicate flag variable → OK

📏Effect Size Reference

Cohen's d (t-tests)

📘 Formula & Benchmarks
d = (M₁ − M₂) / SDpooled
Small: d = 0.2 | Medium: d = 0.5 | Large: d = 0.8

SPSS does not compute Cohen's d directly. Calculate manually from output means and pooled SD, or use the Bootstrapping option.

📝 Report
The groups differed significantly, t(df) = x.xx, p = .xxx, d = x.xx [95% CI: x.xx, x.xx].

η² and ηₚ² (ANOVA)

📘 Formula & Benchmarks
η² = SS_effect / SS_total
ηₚ² = SS_effect / (SS_effect + SS_error)
Small: .01 | Medium: .06 | Large: .14

Request in SPSS: Options → Estimates of effect size
📝 Report
F(df1, df2) = x.xx, p = .xxx, ηₚ² = .xx

r (Correlation & Mann-Whitney)

📘 Benchmarks (Cohen)
Small: r = 0.1 | Medium: r = 0.3 | Large: r = 0.5

For Mann-Whitney: r = Z / √N
📝 Report (Pearson)
r(df) = .xxx, p = .xxx

Odds Ratio (Logistic Regression)

📘 Interpretation
OR = Exp(B) in SPSS output.
OR > 1: predictor increases odds of outcome
OR < 1: predictor decreases odds
OR = 1: no effect
📝 Report
OR = x.xx, 95% CI [x.xx, x.xx], p = .xxx

Hazard Ratio (Cox Regression)

📘 Interpretation
HR = Exp(B) in Cox output.
HR > 1: increased risk/hazard
HR < 1: protective factor
HR = 1: no effect on hazard
📝 Report
HR = x.xx, 95% CI [x.xx, x.xx], p = .xxx

Cramér's V (Chi-Square)

📘 Formula & Benchmarks
V = √(χ²/n·(k−1))
where k = min(rows, columns)
Small: V = 0.1 | Medium: V = 0.3 | Large: V = 0.5

Request in SPSS Crosstabs: Statistics → Phi and Cramer's V
📝 Report
χ²(df, N = xxx) = x.xx, p = .xxx, V = .xx

🧪 Statistical Tests

Descriptive stats, correlation, group comparisons (t-tests, ANOVA), non-parametric tests, chi-square, and survival analysis.

📋Descriptive Statistics

Descriptives (Mean, SD, Skewness)

Quick summary table of means, SD, min/max, skewness, and kurtosis for continuous variables.

Analyze›Descriptive Statistics›Descriptives…
  • Move scale variables to Variable(s)
  • Click Options… → check: Mean, Std. deviation, Min, Max, Skewness, Kurtosis → Continue
  • Click OK
📘 Key Outputs
Skewness: |value| > 2 = problematic skew
Kurtosis: |value| > 7 = heavy tails
Std Error of Skewness/Kurtosis: ratio > ±2 suggests non-normality

Frequencies (Counts & Percentages)

Frequency and percentage tables — ideal for categorical (nominal/ordinal) variables.

Analyze›Descriptive Statistics›Frequencies…
  • Move variables to Variable(s)
  • Click Statistics… → check Mean, Median, Mode, Percentiles as needed → Continue
  • Click Charts… → choose Bar/Pie → Continue → OK

Explore (Detailed + Normality)

Full descriptive summary including 5% trimmed mean, skewness, kurtosis, outlier detection, and normality tests.

Analyze›Descriptive Statistics›Explore…
  • Move continuous variable(s) to Dependent List
  • Move grouping variable to Factor List (optional)
  • Click Statistics… → check Descriptives, Outliers → Continue
  • Click Plots… → check Normality plots with tests, Stem-and-leaf → Continue → OK
📘 Normality Tests Produced
Shapiro-Wilk: Generally preferred — more powerful and accurate for detecting non-normality regardless of sample size
Kolmogorov-Smirnov: Older alternative; less powerful. Only use if specifically required
p > .05 = normally distributed

Crosstabulation + Chi-Square

Two-way frequency table for two categorical variables with association tests.

Analyze›Descriptive Statistics›Crosstabs…
  • Move one variable to Row(s), another to Column(s)
  • Click Statistics… → check Chi-square, Phi and Cramer's V → Continue
  • Click Cells… → check Row, Column, Total percentages → Continue → OK
📘 Theory
χ² = Σ[(O − E)² / E]
Assumption: Expected cell count ≥ 5 in ≥ 80% of cells. If violated, use Fisher's Exact Test (available in same dialog for 2×2 tables).
📝 APA Reporting
χ²(df, N = xxx) = x.xx, p = .xxx, V = .xx

🔗Correlation

Pearson Correlation

Linear association between two normally distributed continuous variables.

Analyze›Correlate›Bivariate…
  • Move variables to Variables box
  • Check ☑ Pearson
  • Check ☑ Flag significant correlations
  • Click Options… → check Means, SD, Exclude cases pairwise → Continue → OK
📘 Theory & Assumptions
r = Σ[(x−x̄)(y−ȳ)] / (n−1)·sₓ·sᵧ
Range: −1 to +1. Assumes: both variables continuous and normally distributed, linear relationship.
Assumptions check: inspect scatterplot for linearity; check normality via Explore.
📝 APA Reporting
r(df) = .xxx, p = .xxx (two-tailed)
EssentialMedical Research

Spearman Rank Correlation

Monotonic association for ordinal data or non-normal continuous variables.

Analyze›Correlate›Bivariate…
  • Move variables to Variables
  • Check ☑ Spearman (uncheck Pearson if not needed)
  • Check ☑ Flag significant correlations → OK
📘 Theory
Applies Pearson formula to the ranks of the data rather than raw values. Use when data is ordinal, non-normal, or contains outliers. Measures monotonic (not necessarily linear) relationships.
📝 APA Reporting
rₛ(df) = .xxx, p = .xxx

Kendall's Tau-b

Association measure for ranked/ordinal data, especially with many tied values or small samples.

Analyze›Correlate›Bivariate…
  • Move variables to Variables
  • Check ☑ Kendall's tau-b → OK
📘 When to Use
Preferred over Spearman when many tied ranks exist (e.g., Likert data). More conservative but more accurate with ties. Range: −1 to +1.
📝 APA Reporting
τb = .xxx, p = .xxx

Partial Correlation

Correlation between two variables controlling for one or more confounding variables.

Analyze›Correlate›Partial…
  • Move variables of interest to Variables
  • Move control/confound variable(s) to Controlling for
  • Click OK
📘 Use Case
Example: Correlation between exercise and cholesterol, controlling for age and BMI. The partial r shows the "pure" relationship after removing the confound's influence.
📝 APA Reporting
r(df) = .xxx, p = .xxx, controlling for [variable].

⚖️Group Comparison — Parametric Tests

One-Sample t-Test

Test whether a sample mean differs from a known/hypothesized population value (e.g., is mean BMI = 25?).

Analyze›Compare Means›One-Sample T Test…
  • Move variable to Test Variable(s)
  • Enter the hypothesized value in Test Value field
  • Click OK
📘 Theory
t = (x̄ − μ₀) / (s / √n)
H₀: μ = μ₀ | Assumptions: continuous variable, approximately normal distribution (or n ≥ 30).
📝 APA Report
t(df) = x.xx, p = .xxx, d = x.xx [95% CI: x.xx, x.xx]

Independent Samples t-Test

Compare means of two independent groups (e.g., treatment vs. control).

Analyze›Compare Means›Independent-Samples T Test…
  • Move DV to Test Variable(s)
  • Move grouping variable to Grouping Variable
  • Click Define Groups… → enter values for Group 1 and Group 2 → Continue
  • Click OK
📘 Theory & Levene's
t = (x̄₁ − x̄₂) / SE_diff
Check Levene's Test first:
p > .05 → Equal variances assumed row
p ≤ .05 → Equal variances not assumed (Welch correction)
📝 APA Report
t(df) = x.xx, p = .xxx, d = x.xx

Welch t-Test (Unequal Variances)

The robust version of the independent t-test when Levene's test is significant (variances unequal).

Analyze›Compare Means›Independent-Samples T Test…

Same dialog as independent t-test. In the output, use the "Equal variances not assumed" row (which applies Welch-Satterthwaite df correction).

📘 Theory
Welch's t-test adjusts the degrees of freedom downward to account for unequal variances, producing a more conservative (but valid) test. Degrees of freedom are no longer whole numbers.
📝 APA Report
t(df_Welch) = x.xx, p = .xxx — note: report Welch-corrected df, not N−2.

Paired Samples t-Test

Compare means from the same subjects measured twice (pre/post, matched pairs, two conditions).

Analyze›Compare Means›Paired-Samples T Test…
  • Click first variable, then Ctrl+click the second
  • Move the pair to Paired Variables
  • Click OK
📘 Theory
t = D̄ / (SD_D / √n), where D = difference scores
Assumption: Difference scores (Variable1 − Variable2) must be normally distributed — check via Explore on the difference variable.
📝 APA Report
t(df) = x.xx, p = .xxx, d = x.xx

One-Way ANOVA

Compare means across 3 or more independent groups (extension of independent t-test to 3+ groups).

Analyze›Compare Means›One-Way ANOVA…
  • Move DV(s) to Dependent List
  • Move grouping variable to Factor
  • Click Post Hoc… → check Tukey (equal variances) or Games-Howell (unequal) → Continue
  • Click Options… → check Descriptive, Homogeneity of variance test, Welch, Brown-Forsythe, Means plot → Continue → OK
📘 Theory
F = MS_between / MS_within = (SS_between/df_between) / (SS_within/df_within)
Assumptions: Normal distribution per group, homogeneity of variance (Levene's), independent observations.
Significant F → run post-hoc tests to find which pairs differ.
📝 APA Report
F(df₁, df₂) = x.xx, p = .xxx, ηₚ² = .xx. Post-hoc: Tukey HSD revealed...

Two-Way (Factorial) ANOVA

Test main effects of two IVs and their interaction on a continuous DV.

Analyze›General Linear Model›Univariate…
  • Move DV to Dependent Variable
  • Move both IVs to Fixed Factor(s)
  • Click Options… → check Descriptive statistics, Estimates of effect size, Homogeneity tests → Continue
  • Click Plots… → set profile plot (Factor 1 on X, Factor 2 as separate lines) → Add → Continue → OK
📘 Theory
Tests three F-ratios: Main Effect A, Main Effect B, and A×B Interaction. An interaction means the effect of one IV depends on the level of the other. Always interpret interaction first.
📝 APA Report
Report all three: F(df₁, df₂) = x.xx, p = .xxx, ηₚ² = .xx for each effect.

Repeated Measures ANOVA

Compare means from the same participants across 3+ time points or conditions.

Analyze›General Linear Model›Repeated Measures…
  • Enter a Within-Subject Factor Name (e.g., "Time") and Number of Levels → Add → Define
  • Move time-point variables to the Within-Subjects Variables slots in order
  • Click Options… → check Descriptive statistics, Estimates of effect size → Continue
  • Click Plots… → profile plot → Continue → OK
📘 Theory & Sphericity
Sphericity Assumption: Variances of the differences between all pairs of time points must be equal.
Test: Analyze → General Linear Model → Repeated Measures → Options → Mauchly's Test

If Mauchly's p < .05 → sphericity violated:
• ε < 0.75 → use Greenhouse-Geisser corrected F
• ε ≥ 0.75 → use Huynh-Feldt correction

Significant result → post-hoc: pairwise comparisons with Bonferroni correction.
📝 APA Report
F(df_GG) = x.xx, p = .xxx, ηₚ² = .xx (if sphericity violated, note GG correction applied).

ANCOVA (Analysis of Covariance)

Compare group means while statistically controlling for a continuous covariate (e.g., compare post-scores adjusting for pre-scores or age).

Analyze›General Linear Model›Univariate…
  • Move DV to Dependent Variable
  • Move grouping variable to Fixed Factor(s)
  • Move covariate to Covariate(s)
  • Click Options… → check Descriptive statistics, Homogeneity tests, Estimates of effect size → Continue → OK
📘 Key Assumption: Homogeneity of Regression Slopes
The covariate must have the same relationship with the DV across all groups. Test this by including the Group × Covariate interaction term in the model. If significant (p < .05), ANCOVA assumptions are violated.
📝 APA Report
After controlling for [covariate], there was a significant group difference, F(df₁, df₂) = x.xx, p = .xxx, ηₚ² = .xx.

MANOVA (Multiple DVs)

Test group differences on two or more dependent variables simultaneously — controls familywise error rate compared to running separate ANOVAs.

Analyze›General Linear Model›Multivariate…
  • Move all DVs to Dependent Variables
  • Move grouping variable to Fixed Factor(s)
  • Click Options… → check Descriptive statistics, Estimates of effect size → Continue → OK
📘 Theory & Outputs
Primary statistic: Wilks' Lambda (Λ) — closer to 0 = stronger group separation.
Also: Pillai's Trace (most robust), Hotelling's Trace, Roy's Largest Root.
If MANOVA is significant → run follow-up univariate ANOVAs with Bonferroni correction.
📝 APA Report
Λ = .xx, F(df₁, df₂) = x.xx, p = .xxx, ηₚ² = .xx

🔢Non-Parametric Tests

Mann-Whitney U Test

Non-parametric alternative to the independent samples t-test. Use when data is ordinal or non-normal.

Analyze›Nonparametric Tests›Legacy Dialogs›2 Independent Samples…
  • Move test variable to Test Variable List
  • Move grouping variable to Grouping Variable → Define Groups → Continue
  • Check ☑ Mann-Whitney U under Test Type → OK
📘 Theory
Ranks all observations from both groups combined, then tests whether the ranks are equally distributed between groups.
Effect size: r = Z / √N
Small: .1 | Medium: .3 | Large: .5
📝 APA Report
U = xxx, z = x.xx, p = .xxx, r = .xx

Wilcoxon Signed-Rank Test

Non-parametric alternative to the paired samples t-test. Use when difference scores are non-normal.

Analyze›Nonparametric Tests›Legacy Dialogs›2 Related Samples…
  • Select both variables → move the pair to Test Pairs
  • Check ☑ Wilcoxon under Test Type → OK
📘 Theory
Ranks the absolute values of differences, then tests whether positive and negative ranks are equally balanced. More powerful than Sign Test.
Effect size: r = Z / √N
📝 APA Report
Z = x.xx, p = .xxx, r = .xx

Kruskal-Wallis H Test

Non-parametric alternative to one-way ANOVA (3+ independent groups, non-normal data).

Analyze›Nonparametric Tests›Legacy Dialogs›K Independent Samples…
  • Move test variable to Test Variable List
  • Move grouping variable to Grouping Variable → Define Range → Continue
  • Check ☑ Kruskal-Wallis H → OK
📘 Post-Hoc After Significant KW
SPSS does not automatically provide post-hoc for KW. To identify which pairs differ:
Run pairwise Mann-Whitney U tests with Bonferroni correction: use α' = .05 / k, where k = number of pairwise comparisons.
📝 APA Report
H(df) = x.xx, p = .xxx. Pairwise comparisons with Bonferroni correction revealed...

Friedman Test

Non-parametric alternative to one-way repeated-measures ANOVA.

Analyze›Nonparametric Tests›Legacy Dialogs›K Related Samples…
  • Move all repeated-measure variables to Test Variables
  • Check ☑ Friedman under Test Type → OK
📘 Theory
Ranks the variables within each case (row), then tests whether the mean ranks differ across conditions. Post-hoc: pairwise Wilcoxon tests with Bonferroni correction.
📝 APA Report
χ²(df, N = xxx) = x.xx, p = .xxx

Chi-Square Goodness-of-Fit

Test whether an observed frequency distribution fits expected proportions (e.g., equal distribution across categories).

Analyze›Nonparametric Tests›Legacy Dialogs›Chi-Square…
  • Move categorical variable to Test Variable List
  • Under Expected Values: choose All categories equal or enter specific expected proportions
  • Click OK
📘 Theory
χ² = Σ[(O − E)² / E]
Tests H₀: observed frequencies = expected frequencies.
📝 APA Report
χ²(df) = x.xx, p = .xxx

Binomial Test

Test whether the proportion of a binary outcome matches a hypothesized value (e.g., is cure rate = 50%?).

Analyze›Nonparametric Tests›Legacy Dialogs›Binomial…
  • Move binary variable to Test Variable List
  • Enter Test Proportion (e.g., 0.50 for 50%)
  • Click OK
📘 Theory
Uses binomial distribution to compare observed proportion against H₀. Exact test — no large-sample approximation needed. Outputs exact significance (p-value).
📝 APA Report
The observed proportion (.xx) was significantly different from the expected proportion of .50, p = .xxx (exact, two-tailed).

Sign Test

Simplest paired non-parametric test — counts which direction the differences go (positive vs. negative signs).

Analyze›Nonparametric Tests›Legacy Dialogs›2 Related Samples…
  • Move pair of variables to Test Pairs
  • Check ☑ Sign under Test Type → OK
📘 Theory
Less powerful than Wilcoxon because it ignores the magnitude of differences — only uses direction. Use when only the sign (direction) of change is reliable.

McNemar Test (Paired Proportions)

Test whether proportions change significantly in a paired/matched design (e.g., before/after treatment — binary outcome).

Analyze›Descriptive Statistics›Crosstabs…
  • Move Pre variable to Row(s), Post variable to Column(s)
  • Click Statistics… → check ☑ McNemar → Continue → OK
📘 Theory
Uses only the discordant pairs (cases where response changed). Tests whether the probability of changing from No→Yes equals the probability of changing from Yes→No.
Use when: binary DV, paired/matched design, comparing pre vs. post proportions.
📝 APA Report
McNemar χ²(1) = x.xx, p = .xxx

⏱️Survival Analysis

🏥 Critical in Medical Research
Survival analysis handles time-to-event data with censored observations — essential for clinical trials, oncology, and epidemiology.

Kaplan-Meier Survival Curve

Estimate and plot survival probability over time, accounting for censored observations.

Analyze›Survival›Kaplan-Meier…
  • Move time variable (duration) to Time box
  • Move status variable (event: 0=censored, 1=event) to Status
  • Click Define Event… → enter value for event occurred (usually 1) → Continue
  • (Optional) Move grouping variable to Factor for group comparison
  • Click Options… → check Survival table, At risk → Continue → OK
📘 Theory
The KM estimator calculates the probability of surviving past each event time as a step function: S(t) = Π[(nᵢ − dᵢ) / nᵢ]
where nᵢ = at risk, dᵢ = events at time tᵢ. Censoring accounts for participants lost to follow-up or study end.
📝 APA Report
Median survival time was xx months (95% CI: xx–xx). The x-year survival probability was xx%.
CriticalOncology / Clinical Trials

Log-Rank Test (Compare Survival Curves)

Test whether two or more survival curves are statistically different (non-parametric comparison).

Analyze›Survival›Kaplan-Meier…›Compare Factor
  • Setup KM with a Factor (grouping) variable
  • Click Compare Factor button
  • Check ☑ Log rank (most common), ☑ Breslow (weights early events), ☑ Tarone-Ware
  • Select Pooled over strata → Continue → OK
📘 Theory
Log-rank gives equal weight to all time points. Breslow gives more weight to early events. Use Log-rank when hazards are proportional over time; Breslow when early events are more important.
📝 APA Report
Log-rank test: χ²(df) = x.xx, p = .xxx. Survival differed significantly between groups.

Cox Proportional Hazards Regression

Multivariable survival model — estimate hazard ratios while adjusting for covariates.

Analyze›Survival›Cox Regression…
  • Move time variable to Time
  • Move status variable to Status → Define Event → Continue
  • Move covariates to Covariates
  • Move categorical variables to Categorical → set reference category → Continue
  • Click Options… → check CI for Exp(B) → Continue → OK
📘 Theory & Proportional Hazards Assumption
Cox model: h(t) = h₀(t) · exp(β₁x₁ + β₂x₂ + ...)
Exp(B) = Hazard Ratio (HR)
HR > 1: increased hazard | HR < 1: protective factor
PH Assumption: Test using time-covariate interactions. If significant interaction, PH is violated — consider stratified Cox or time-varying covariates.
📝 APA Report
HR = x.xx, 95% CI [x.xx, x.xx], p = .xxx

Alternative to KM for large samples — groups survival into time intervals rather than individual event times.

📉Linear Regression

Simple / Multiple Linear Regression

Predict a continuous outcome from one or more predictors. Understand which predictors matter and by how much.

Analyze›Regression›Linear…
  • Move outcome (DV) to Dependent
  • Move predictor(s) to Independent(s)
  • Choose Method: Enter (all at once), Stepwise, Forward, Backward
  • Click Statistics… → check: Estimates, Model fit, R² change, Descriptives, Collinearity diagnostics, Part and partial correlations → Continue
  • Click Plots… → ZRESID (Y) vs. ZPRED (X), check Normal P-P plot → Continue → OK
📘 Theory & Assumptions
Ŷ = b₀ + b₁X₁ + b₂X₂ + ... + ε
R²: proportion of variance explained
B: unstandardized coefficient (raw units)
Beta (β): standardized coefficient (compare relative importance)

Assumptions (LINE):
L = Linearity | I = Independence of errors | N = Normality of residuals | E = Equal variance (homoscedasticity)
📝 APA Report
The model significantly predicted [DV], R² = .xx, F(df₁, df₂) = x.xx, p = .xxx. [Predictor] significantly contributed, B = x.xx, β = .xx, t(df) = x.xx, p = .xxx.

Hierarchical Regression (Block Entry)

Enter predictors in theoretically ordered blocks to test how much variance each set adds (ΔR²).

Analyze›Regression›Linear…
  • Add Block 1 predictors to Independent(s)
  • Click Next → Block 2 appears → add second set of predictors
  • Click Statistics… → check R squared change → Continue → OK
📘 Interpreting ΔR²
Each block's ΔR² (R² change) and associated F-change test tells you whether Block 2 explains significantly more variance above and beyond Block 1. Report ΔR², ΔF, and its p-value.
📝 APA Report
Block 2 variables explained an additional xx% of variance, ΔR² = .xx, ΔF(df₁, df₂) = x.xx, p = .xxx.

Collinearity Diagnostics (VIF / Tolerance)

Detect multicollinearity — when predictors are too highly correlated with each other.

Analyze›Regression›Linear…›Statistics…›☑ Collinearity diagnostics
📘 Interpretation
Tolerance = 1 − R² (variance not explained by other predictors)
VIF = 1 / Tolerance

VIF < 5: acceptable
VIF 5–10: moderate concern
VIF > 10: serious multicollinearity → remove or combine predictors
Critical Diagnostic

Residuals & Influence Diagnostics

Save residuals, leverage, Cook's distance, and DfBeta to detect outliers and influential cases.

Analyze›Regression›Linear…›Save…
  • Under Residuals: check Standardized, Studentized
  • Under Distances: check Cook's, Mahalanobis, Leverage
  • Under Influence Statistics: check DfBeta(s)
  • Continue → OK (new variables created in dataset)
📘 Cutoffs
Cook's D > 1 or > 4/n: influential case
Leverage > 2(k+1)/n: high leverage
Standardized residual |z| > 3: outlier
Mahalanobis distance: compare to chi-square critical value at p < .001, df = number of predictors

Curve Estimation (Non-linear Trends)

Fit and compare multiple functional forms (linear, quadratic, cubic, logarithmic, etc.) to your data.

Analyze›Regression›Curve Estimation…
  • Move DV to Dependent(s) and IV to Independent
  • Check desired model types: Linear, Quadratic, Cubic, Logarithmic, Power, Exponential
  • Check ☑ Plot models → OK
📘 When to Use
Use when a scatterplot suggests a curved relationship. Compare R² values across models and choose the simplest that fits well. Quadratic adds one bend; cubic adds two.

🔀Logistic & GLM Regression

Binary Logistic Regression

Predict a binary (yes/no, 0/1) outcome from continuous and/or categorical predictors. Outputs Odds Ratios.

Analyze›Regression›Binary Logistic…
  • Move binary DV to Dependent
  • Move predictors to Covariates
  • Click Categorical… → move categorical predictors → set reference category → Continue
  • Click Options… → check CI for Exp(B), Hosmer-Lemeshow goodness of fit, Classification plots → Continue → OK
📘 Theory & Key Outputs
log[P/(1−P)] = b₀ + b₁X₁ + b₂X₂ + ...
Exp(B) = Odds Ratio (OR)
−2LL: model fit (lower = better)
Nagelkerke R²: pseudo-R² (variance explained)
Hosmer-Lemeshow: p > .05 = good model fit
Classification table: % correctly classified

Key Assumptions:
• Independent observations: each case must be independent (no repeated measures)
• Linearity of the logit: continuous predictors must have a linear relationship with the log-odds — test using Box-Tidwell procedure or adding ln(X)×X interaction terms
• No severe multicollinearity (check VIF < 10)
• No influential outliers (check standardized residuals)
📝 APA Report
OR = x.xx, 95% CI [x.xx, x.xx], p = .xxx. Model fit: Nagelkerke R² = .xx, Hosmer-Lemeshow χ²(8) = x.xx, p = .xxx.

Predict an unordered categorical outcome with 3+ categories (e.g., disease type A/B/C) from predictors.

Runs k−1 binary logistic regressions against the reference category. Each set of ORs compares one category vs. the reference. Appropriate when outcome has 3+ unordered categories.
📝 APA Report
Compared to [reference], [category] had OR = x.xx, 95% CI [x.xx, x.xx], p = .xxx.

Poisson Regression (GLM)

Predict a count outcome (number of events) — hospital admissions, infection episodes, medication doses.

  • Click Model → add terms → Continue → OK

log(μ) = b₀ + b₁X₁ + ...
Exp(B) = Incidence Rate Ratio (IRR)

Analyze repeated measures and clustered data with correlated observations — handles missing data better than traditional RM ANOVA.

Fixed effects: predictors you're interested in (time, treatment, covariates)
Random effects: account for individual variation (random intercept = each person has their own baseline; random slope = each person changes at their own rate)

🔬Scale & Factor Analysis

Cronbach's Alpha (Internal Consistency)

Assess whether multiple items on a questionnaire/scale measure the same underlying construct.

Analyze›Scale›Reliability Analysis…
  • Move all scale items to Items
  • Keep Model as Alpha
  • Click Statistics… → check: Item, Scale, Scale if item deleted, Corrected item-total correlations, Inter-item → Continue → OK
📘 Theory & Benchmarks
Ranges 0–1. Measures average inter-item correlation weighted by number of items.
α ≥ 0.9 = Excellent
α ≥ 0.8 = Good
α ≥ 0.7 = Acceptable
α < 0.7 = Questionable

Check "Cronbach's Alpha if Item Deleted": if deleting an item raises α substantially, consider removing that item.
📝 APA Report
Internal consistency was [excellent/good/acceptable] (α = .xx, n items = xx).

Inter-Rater Reliability (ICC)

Assess agreement between multiple raters measuring the same subjects.

Analyze›Scale›Reliability Analysis…
  • Move rater variables to Items
  • Change Model to Intraclass correlation coefficient
  • Set Model (Two-Way Mixed = raters fixed; Two-Way Random = raters random sample)
  • Set Type (Consistency vs. Absolute Agreement) → Statistics → CI → OK
📘 ICC Benchmarks (Koo & Mae, 2016)
ICC < 0.5: Poor | 0.5–0.75: Moderate | 0.75–0.90: Good | > 0.90: Excellent

Consistency: raters use scales in same relative way
Absolute Agreement: raters give exact same values
📝 APA Report
The ICC was .xx (95% CI [.xx, .xx]), indicating [good/excellent] reliability.

Exploratory Factor Analysis (EFA)

Identify latent factors underlying a set of observed variables — use to develop or validate a scale structure.

Analyze›Dimension Reduction›Factor…
  • Move all indicator items to Variables
  • Click Extraction… → Method: Principal Axis Factoring; Eigenvalue > 1; check Scree plot → Continue
  • Click Rotation… → Oblique: Promax (if factors likely correlated); Orthogonal: Varimax → Continue
  • Click Options… → check Sorted by size, Suppress small coefficients (.30) → Continue → OK
📘 Key Decisions & Outputs
KMO > 0.6: adequate for FA | Bartlett's p < .05: significant correlations exist
Communality > 0.3: item variance explained
Loading ≥ .40: item loads on factor
Use Pattern Matrix for oblique; Rotated Component Matrix for orthogonal
Cross-loading: same item loads ≥.30 on 2+ factors — consider removing
📝 APA Report
EFA revealed xx factors explaining xx% of total variance (KMO = .xx, Bartlett's χ²(df) = x.xx, p < .001).

Principal Components Analysis (PCA)

Reduce many correlated variables into fewer uncorrelated components that capture maximum variance.

Analyze›Dimension Reduction›Factor…
  • Move variables to Variables
  • Click Extraction… → Method: Principal Components; check Scree plot → Continue
  • Click Rotation… → Varimax → Continue
  • Click Scores… → check Save as variables → Continue → OK
📘 PCA vs. EFA
PCA: data reduction — components explain as much variance as possible (includes unique variance). Use when you want to reduce dimensions.
EFA: latent variable modeling — factors explain shared variance only. Use when modeling underlying constructs.

Hierarchical Cluster Analysis

Group cases or variables into a hierarchy of clusters — produces a dendrogram for visual inspection.

Analyze›Classify›Hierarchical Cluster…

  • Click Plots → check Dendrogram → Continue → OK

Examine the dendrogram: cut the tree where the vertical lines are longest (biggest jumps in fusion distances). Also check the agglomeration schedule — large jumps in the distance column indicate where to cut.

ℹ️ General APA Rules for Statistics
1. Always report exact p-values (e.g., p = .023), not just "p < .05" — except when p < .001.
2. Always report an effect size alongside every significance test.
3. Report test statistic, degrees of freedom, p-value, and effect size in one complete statement.
4. Degrees of freedom appear in parentheses after the test statistic letter: F(2, 87), t(43), χ²(3).
5. Use leading zeros for values that cannot exceed 1: p = .043 (not p = 0.043). No leading zero for r and β.
