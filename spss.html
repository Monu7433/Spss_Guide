🗄️ Data Management

Opening files, editing data, transforming variables, and managing datasets via SPSS menus.

📂 Opening & Saving Files

Open Data File

Import an existing SPSS or Excel dataset into the Data Editor.

File›Open›Data…
  • Browse to your file location
  • Change Files of type to match format (e.g., Excel, CSV, .sav)
  • Click Open
  • For Excel: check Read variable names from first row → OK

Save / Save As

Save your dataset in SPSS format (.sav) or export to another format.

Save (same file)
File›Save
Save as new name/format
File›Save As…

Select save type: SPSS (.sav), Excel, CSV, etc.

Import CSV / Text File

Read delimited text files with SPSS's Text Import Wizard.

File›Import Data›CSV Data…
  • Select your .csv file → Next
  • Confirm delimiter type (comma, tab, space)
  • Check Variable names at top of file if applicable
  • Click Finish

Import Excel File

Open .xlsx or .xls files directly into SPSS.

File›Import Data›Excel…
  • Select your Excel file
  • Choose the correct Worksheet from dropdown
  • Check Read variable names from first row of data
  • Click OK
🔧 Transforming Variables

Compute New Variable

Create a new variable using arithmetic, functions, or logical expressions.

Transform›Compute Variable…
  • Enter a name in Target Variable
  • Build expression in Numeric Expression box using variable list and function buttons
  • Optionally click If… to apply a condition
  • Click OK

Recode Into Same Variable

Change existing values of a variable in place.

Transform›Recode into Same Variables…
  • Move target variable(s) to Variables box
  • Click Old and New Values…
  • Enter each old value → new value pair → Add
  • Click Continue → OK

Recode Into Different Variable

Recode a variable into a new variable (preserves original).

Transform›Recode into Different Variables…
  • Move source variable to Input Variable → Output Variable
  • Enter a Name for the new variable → Change
  • Click Old and New Values… and define mappings
  • Continue → OK

Visual Binning (Categorize)

Group a continuous variable into categories visually.

Transform›Visual Binning…
  • Move variable into Variables to Bin → Continue
  • Enter a Binned Variable Name
  • Click Make Cutpoints… or drag boundaries on histogram
  • Assign category Labels → OK

Sort Cases

Sort all rows in ascending or descending order by one or more variables.

Data›Sort Cases…
  • Move sort key variable(s) to Sort by
  • Choose Ascending or Descending for each key
  • Click OK

Select Cases (Filter)

Restrict analysis to a subset of cases matching a condition.

Data›Select Cases…
  • Choose If condition is satisfied → click If…
  • Enter logical condition (e.g., age > 18)
  • Choose action: Filter (keeps all) or Delete
  • Continue → OK

Filtered-out rows show a slash through row number. Reset via Data › Select Cases › All Cases.

Split File (Group Analysis)

Run analyses separately for each group without filtering.

Data›Split File…
  • Select Compare groups or Organize output by groups
  • Move grouping variable to Groups Based on
  • Click OK

Always reset: Data › Split File › Analyze all cases when done.

Merge / Add Cases or Variables

Combine two datasets by stacking rows or adding columns.

Add rows (cases)
Data›Merge Files›Add Cases…
Add columns (variables)
Data›Merge Files›Add Variables…

Variable Properties & Labels

Set variable labels, value labels, measure type, and missing values.

Data Editor›Variable View tab
  • Click the Label cell to add a descriptive label
  • Click the Values cell → … button → enter code + label pairs
  • Click Missing cell → define user-missing values
  • Set Measure: Nominal, Ordinal, or Scale
⚠️ Always Check Variable View First
Before running analyses, switch to Variable View (tab at bottom of Data Editor) to confirm variables have correct measurement levels (Scale/Ordinal/Nominal). Wrong levels can cause incorrect analysis options to appear.
📊 Descriptive Statistics

Summarize and explore your data using frequency tables, descriptives, crosstabs, and explore.

📋 Summary Statistics

Descriptive Statistics (Mean, SD, etc.)

Get mean, std. deviation, min, max, range, and more for scale variables.

Analyze›Descriptive Statistics›Descriptives…
  • Move scale variables to Variable(s)
  • Click Options… → check: Mean, Std. deviation, Minimum, Maximum, Skewness, Kurtosis
  • Continue → OK

Output: Descriptive Statistics table in Output Viewer.

Frequencies (Counts & %)

Get count and percentage tables, ideal for categorical variables.

Analyze›Descriptive Statistics›Frequencies…
  • Move variables to Variable(s) box
  • Click Statistics… → check Mean, Median, Mode, Std. Deviation, Percentiles as needed → Continue
  • Click Charts… → choose Bar/Histogram if desired → Continue
  • Click OK

Explore (Detailed with Normality Tests)

Deep descriptive summary including outlier detection and normality tests.

Analyze›Descriptive Statistics›Explore…
  • Move continuous variable(s) to Dependent List
  • Optionally move grouping variable to Factor List
  • Click Statistics… → check Descriptives, Outliers → Continue
  • Click Plots… → check Normality plots with tests, Stem-and-leaf → Continue → OK

Produces Shapiro-Wilk and Kolmogorov-Smirnov normality tests.

Crosstabulation

Two-way frequency table for two categorical variables (with Chi-Square option).

Analyze›Descriptive Statistics›Crosstabs…
  • Move one variable to Row(s) and another to Column(s)
  • Click Statistics… → check Chi-square, Phi and Cramer's V → Continue
  • Click Cells… → check Row, Column, Total percentages → Continue
  • Click OK

Case Summaries

List individual case values with optional group subtotals.

Analyze›Reports›Case Summaries…
  • Move variables to display into Variables
  • Move grouping variable to Grouping Variables (optional)
  • Check Statistics for subtotals → Continue → OK

Compare Means (Group Means Table)

See mean, std. deviation and count broken down by a grouping variable.

Analyze›Compare Means›Means…
  • Move the continuous variable to Dependent List
  • Move grouping variable to Independent List
  • Click Options… → select statistics → Continue → OK
ℹ️ Choosing the Right Summary Tool
Use Frequencies for nominal/ordinal variables. Use Descriptives for scale variables when you just need means and SDs quickly. Use Explore when you need normality tests before parametric analyses.
📈 Regression Analysis

Run linear, logistic, and other regression models through SPSS menus.

📉 Linear Regression

Simple / Multiple Linear Regression

Predict a continuous outcome from one or more continuous/categorical predictors.

Analyze›Regression›Linear…
  • Move outcome (DV) to Dependent
  • Move predictor(s) to Independent(s)
  • Choose Method: Enter, Stepwise, Forward, Backward
  • Click Statistics… → check: Estimates, Model fit, R squared change, Descriptives, Collinearity diagnostics → Continue
  • Click Plots… → add ZRESID vs ZPRED, check Normal probability plot → Continue → OK

Output includes: Model Summary (R², adjusted R²), ANOVA table, Coefficients table with B, Beta, t, Sig.

Hierarchical Regression (Block Entry)

Enter predictors in ordered blocks to test incremental variance explained.

Analyze›Regression›Linear…
  • Add Block 1 predictors to Independent(s)
  • Click Next to create Block 2 → add second set
  • Under Statistics…, check R squared change
  • Continue → OK

Each block's ΔR² and F-change significance will appear in Model Summary.

Regression Diagnostics

Check residuals, leverage, influence, and multicollinearity.

Analyze›Regression›Linear…›Save…
  • Under Residuals: check Standardized, Studentized
  • Under Distances: check Cook's, Leverage values
  • Under Influence Statistics: check DfBeta(s)
  • Continue → OK (saved as new variables in dataset)
🔀 Logistic & Other Regression

Binary Logistic Regression

Predict a binary (0/1) outcome from continuous or categorical predictors.

Analyze›Regression›Binary Logistic…
  • Move binary DV to Dependent
  • Move predictors to Covariates
  • For categorical predictors: click Categorical… → move to Categorical Covariates → set contrast type → Continue
  • Click Options… → check CI for Exp(B), Hosmer-Lemeshow goodness of fit → Continue → OK

Output: Variables in Equation table with Exp(B) = Odds Ratios and 95% CI.

Ordinal Logistic Regression

Model an ordinal outcome (e.g., Likert scale ratings).

Analyze›Regression›Ordinal…
  • Move ordinal DV to Dependent
  • Move continuous predictors to Covariate(s)
  • Move categorical predictors to Factor(s)
  • Under Output…: check parameter estimates, goodness of fit → Continue → OK

Curve Estimation (Non-linear Trend)

Fit various functional forms (linear, quadratic, logarithmic, etc.) to your data.

Analyze›Regression›Curve Estimation…
  • Move DV to Dependent(s) and IV to Independent Variable
  • Check desired model types: Linear, Quadratic, Cubic, Logarithmic, etc.
  • Check Plot models for a visual comparison
  • Click OK
⚖️ Group Comparison Tests

Compare means across groups using t-tests, ANOVA, and related procedures.

🔬 T-Tests

One-Sample T-Test

Test whether a sample mean differs from a known / hypothesized value.

Analyze›Compare Means›One-Sample T Test…
  • Move variable to Test Variable(s)
  • Enter the hypothesized value in Test Value field
  • Click OK

Output: t-statistic, df, Sig. (2-tailed), and Mean Difference with 95% CI.

Independent Samples T-Test

Compare means of two independent groups.

Analyze›Compare Means›Independent-Samples T Test…
  • Move DV to Test Variable(s)
  • Move grouping variable to Grouping Variable
  • Click Define Groups… → enter values for Group 1 and Group 2 → Continue
  • Click OK

Check Levene's Test: if Sig. < .05, use "Equal variances not assumed" row.

Paired Samples T-Test

Compare means from the same subjects measured twice (pre-post, matched pairs).

Analyze›Compare Means›Paired-Samples T Test…
  • Click the first variable in the list, then Ctrl+click the second
  • Move the pair to Paired Variables
  • Click OK

Output shows paired differences mean, SD, t, df, and Sig.

📊 ANOVA

One-Way ANOVA

Compare means across three or more independent groups.

Analyze›Compare Means›One-Way ANOVA…
  • Move DV(s) to Dependent List
  • Move grouping variable to Factor
  • Click Post Hoc… → check Tukey (equal variances) or Games-Howell (unequal) → Continue
  • Click Options… → check Descriptive, Homogeneity of variance test, Welch → Continue → OK

Two-Way (Factorial) ANOVA

Test main effects and interaction of two independent variables on a continuous DV.

Analyze›General Linear Model›Univariate…
  • Move DV to Dependent Variable
  • Move both IVs to Fixed Factor(s)
  • Click Plots… → set up a profile plot → Add → Continue
  • Click Post Hoc… → select factors → check Tukey → Continue → OK

Interaction term (AxB) is automatically included. Check Sig. column for each effect.

Repeated Measures ANOVA

Compare means from the same participants across multiple time points or conditions.

Analyze›General Linear Model›Repeated Measures…
  • Enter a Within-Subject Factor Name and Number of Levels → Add → Define
  • Move time-point variables to Within-Subjects Variables slots
  • Click Options… → check Descriptive statistics, Estimates of effect size → Continue
  • Click Plots… → profile plot → Continue → OK

Check Mauchly's Test of Sphericity. If violated (p < .05) use Greenhouse-Geisser correction.

ANCOVA (Covariate Control)

Compare group means while controlling for a continuous covariate.

Analyze›General Linear Model›Univariate…
  • Move DV to Dependent Variable
  • Move grouping variable to Fixed Factor(s)
  • Move covariate(s) to Covariate(s)
  • Options: check Descriptive statistics, Homogeneity tests → Continue → OK

MANOVA (Multiple DVs)

Test group differences on two or more dependent variables simultaneously.

Analyze›General Linear Model›Multivariate…
  • Move all DVs to Dependent Variables
  • Move grouping variable to Fixed Factor(s)
  • Options: check Descriptive statistics, Estimates of effect size → Continue → OK

Report Wilks' Lambda from the Multivariate Tests table.

🔢 Non-Parametric Tests

Distribution-free alternatives when normality or other parametric assumptions are violated.

Mann-Whitney U Test

Non-parametric alternative to the independent samples t-test.

Legacy dialog
Analyze›Nonparametric Tests›Legacy Dialogs›2 Independent Samples…
  • Move test variable to Test Variable List
  • Move grouping variable to Grouping Variable → Define Groups (enter values)
  • Check Mann-Whitney U under Test Type → OK

Wilcoxon Signed-Rank Test

Non-parametric paired test (alternative to paired t-test).

Analyze›Nonparametric Tests›Legacy Dialogs›2 Related Samples…
  • Select both variables → move the pair to Test Pairs
  • Check Wilcoxon under Test Type → OK

Kruskal-Wallis Test

Non-parametric alternative to one-way ANOVA (3+ independent groups).

Analyze›Nonparametric Tests›Legacy Dialogs›K Independent Samples…
  • Move test variable to Test Variable List
  • Move grouping variable to Grouping Variable → Define Range → Continue
  • Check Kruskal-Wallis H → OK

Friedman Test

Non-parametric alternative to one-way repeated measures ANOVA.

Analyze›Nonparametric Tests›Legacy Dialogs›K Related Samples…
  • Move all repeated-measure variables to Test Variables
  • Check Friedman under Test Type → OK

Chi-Square Goodness-of-Fit

Test whether an observed frequency distribution matches expected proportions.

Analyze›Nonparametric Tests›Legacy Dialogs›Chi-Square…
  • Move categorical variable to Test Variable List
  • Under Expected Values: choose All categories equal or enter specific expected values
  • Click OK

Binomial Test

Test whether the proportion of a binary variable matches a specified proportion.

Analyze›Nonparametric Tests›Legacy Dialogs›Binomial…
  • Move binary variable to Test Variable List
  • Enter Test Proportion (e.g., 0.5 for 50/50)
  • Click OK
✅ Automated Nonparametric Tests (SPSS v21+)
Use Analyze › Nonparametric Tests › One Sample / Related Samples / Independent Samples… for a guided wizard that automatically selects the appropriate test based on your data — no need to remember which legacy dialog to use!
🔬 Reliability & Scale Analysis

Assess internal consistency of questionnaire scales and explore scale structure.

Reliability Analysis (Cronbach's α)

Measure internal consistency of a multi-item scale.

Analyze›Scale›Reliability Analysis…
  • Move all scale items to Items
  • Keep Model as Alpha (Cronbach's)
  • Click Statistics… → check: Item, Scale, Scale if item deleted, Correlations, Inter-item → Continue
  • Click OK

Target: α ≥ .70 (acceptable); α ≥ .80 (good). Check "Cronbach's Alpha if Item Deleted" to identify weak items.

Inter-Rater Reliability (ICC)

Assess agreement between raters using Intraclass Correlation Coefficient.

Analyze›Scale›Reliability Analysis…
  • Move rater variables to Items
  • Change Model to Intraclass correlation coefficient
  • Set Model (Two-Way Mixed/Random) and Type (Consistency/Absolute Agreement)
  • Statistics: check CI → Continue → OK

Multidimensional Scaling (Perceptual Mapping)

Visualize similarities or distances between items/stimuli in 2D/3D space.

Analyze›Scale›Multidimensional Scaling (ALSCAL)…
  • Move proximity variables to Variables
  • Set data type (distances vs. similarities)
  • Choose Number of Dimensions (usually 2)
  • Options: display plot → OK
🧮 Factor & Cluster Analysis

Explore latent structures, reduce dimensions, and group cases.

🔍 Factor Analysis (EFA & PCA)

Exploratory Factor Analysis (EFA)

Identify latent factors underlying a set of observed variables.

Analyze›Dimension Reduction›Factor…
  • Move all indicator items to Variables
  • Click Extraction… → Method: Principal Axis Factoring or Maximum Likelihood; choose Based on Eigenvalue > 1 → Continue
  • Click Rotation… → Method: Promax (oblique) or Varimax (orthogonal) → Continue
  • Click Options… → check Sorted by size, Suppress small coefficients (.30) → Continue → OK

Review Pattern Matrix (oblique) or Rotated Component Matrix (orthogonal). Look for loadings ≥ .40.

Principal Components Analysis (PCA)

Reduce many variables to fewer uncorrelated components.

Analyze›Dimension Reduction›Factor…
  • Move variables to Variables
  • Click Extraction… → Method: Principal Components → Continue
  • Click Rotation… → Varimax → Continue
  • Click Scores… → check Save as variables if you want component scores → Continue → OK

Check the Scree Plot (Extraction → Display: Scree plot) to identify the elbow point for number of components.

Confirmatory Factor Analysis (CFA)

Test a pre-specified factor structure (requires AMOS add-on or script).

File›New›IBM SPSS Amos
  • Open AMOS Graphics from Start Menu or SPSS File menu
  • Click File › Data Files… → link your SPSS dataset
  • Draw latent factors (ellipses) and observed variables (rectangles) using toolbar
  • Click Analyze › Calculate Estimates to run → View output via Analyze › View Text…

Report CFI ≥ .95, RMSEA ≤ .06, SRMR ≤ .08 for good fit.

🗃️ Cluster Analysis

Hierarchical Cluster Analysis

Group cases or variables into clusters with a dendrogram.

Analyze›Classify›Hierarchical Cluster…
  • Move variables to Variable(s)
  • Choose to cluster Cases or Variables
  • Method: Ward's (most common for cases)
  • Plots: check Dendrogram → Continue → OK

K-Means Cluster Analysis

Partition cases into a specified number (k) of clusters.

Analyze›Classify›K-Means Cluster…
  • Move clustering variables to Variables
  • Set Number of Clusters (k)
  • Click Save… → check Cluster membership to save cluster ID as new variable
  • Options: check Cluster information for each case → Continue → OK
🎨 Charts & Visualisation

Build bar charts, histograms, scatterplots, and more using SPSS Chart Builder.

📊 Chart Builder (Primary Method)

Open Chart Builder

SPSS's drag-and-drop chart creation interface.

Graphs›Chart Builder…
  • Click OK on the welcome dialog to proceed
  • Choose a chart type from the Gallery at the bottom left
  • Drag a chart thumbnail to the canvas preview area
  • Drag variables from the variable list onto axis drop zones
  • Set options in Element Properties panel → OK

Double-click a chart in Output Viewer to open Chart Editor for formatting.

Bar Chart

Display counts or means for categorical groups.

Graphs›Chart Builder…›Gallery: Bar
  • Drag a Simple Bar thumbnail to canvas
  • Drag categorical variable to X-Axis drop zone
  • Drag continuous variable to Y-Axis (or leave for Count)
  • In Element Properties: set Statistic to Mean or Count → Apply → OK

Histogram

Visualize the distribution of a continuous variable.

Graphs›Chart Builder…›Gallery: Histogram
  • Drag Simple Histogram to canvas
  • Drag continuous variable to X-Axis
  • In Element Properties: check Display normal curve if needed → Apply → OK

Scatterplot

Explore relationship between two continuous variables.

Graphs›Chart Builder…›Gallery: Scatter/Dot
  • Drag Simple Scatter to canvas
  • Drag X variable to X-Axis, Y variable to Y-Axis
  • Optionally drag grouping variable to Color drop zone for coloring by group
  • To add regression line: Chart Editor → Elements › Fit Line at Total

Boxplot

Show median, quartiles, and outliers by group.

Graphs›Chart Builder…›Gallery: Boxplot
  • Drag Simple Boxplot to canvas
  • Drag continuous variable to Y-Axis
  • Drag categorical variable to X-Axis
  • OK

Line Chart

Display trends over categories or time using connected points.

Graphs›Chart Builder…›Gallery: Line
  • Drag Simple Line to canvas
  • Drag time/category variable to X-Axis
  • Drag measure to Y-Axis
  • For multiple groups: drag grouping variable to Color → OK
✏️ Editing Charts

Chart Editor

Modify colors, fonts, axes, titles, and add fit lines after chart is created.

Output Viewer›Double-click chart
  • Click any element to select it, then right-click for options
  • Double-click an element to open its Properties dialog
  • Use Elements menu to add fit lines, reference lines, error bars
  • Use Options menu to change chart size
  • Close Chart Editor window to save changes to output

Export Chart as Image

Save a chart as PNG, TIFF, EMF, or PDF.

Output Viewer›Right-click chart›Export…
  • Select Export format: PNG, TIFF, JPG, EMF, PDF
  • Set file path and name
  • Adjust Image size and Resolution (DPI) for publication quality
  • Click OK

For journals: use TIFF at 300+ DPI; for presentations: PNG at 150+ DPI.

📄 Output & Results Management

Navigate, export, and manage SPSS Output Viewer results.

Save Output File (.spv)

Save your Output Viewer results for future reference.

File›Save

Or use Save As to choose a location:

File›Save As…›SPSS Output (.spv)

Export Output to Word / PDF / Excel

Export all or selected results to various formats for reporting.

File›Export…
  • Under Export Format: choose Word (.docx), PDF, Excel (.xlsx), HTML, or PowerPoint
  • Under Export What: All visible output, Selected output, All output except notes
  • Set file path → OK

Copy Table to Word/Excel

Quickly copy a single output table to another application.

Output Viewer›Right-click table
  • Click the table to select it
  • Right-click → Copy (for Word) or Copy Special…
  • For Excel pivot-ready format: Copy Special… → Tab-separated values
  • Paste into Word, Excel, or PowerPoint

Delete Unwanted Output Items

Clean up the Output Viewer by removing items.

Output Viewer›Click item in left panel›Delete key

Use Ctrl+Click to select multiple items in the left outline panel before deleting.

Pivot Table Editor (Edit a Table)

Modify, reformat, or add footnotes to a results table.

Output Viewer›Double-click table
  • Double-click opens the Pivot Table Editor
  • Drag row/column labels to pivot structure via Pivot › Pivot Trays…
  • Format cells via Format › Cell Properties
  • Add/edit footnotes via Insert › Footnote
  • Click outside to deactivate editor

Syntax Log (Copy Last Command)

See the syntax generated by your menu actions for repeatability.

Edit›Options…›Viewer tab
  • Check Display commands in the log
  • Now all menu-driven commands appear in output as syntax
  • Right-click the Log entry → Copy to Syntax Editor to save and re-run

This is an excellent way to learn SPSS syntax from your own menu actions!

Undo / Redo in Data Editor

Reverse or redo the last data editing actions.

Undo
Edit›Undo
Keyboard shortcut
Ctrl+Z

SPSS supports unlimited undo for data changes within a session.

SPSS Version & System Info

Check your SPSS version, license, and installed modules.

Help›About IBM SPSS Statistics

Use Help › Topics (or press F1) for context-sensitive help on any open dialog.
